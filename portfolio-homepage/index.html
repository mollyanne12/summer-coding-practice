Projects

These projects demonstrate the technical and problem-solving skills I have developed during my Software Engineering degree. Each project includes an explanation of what I built, the technologies I used and how I approached the development process.

  • Auctionary

    Project type: Full-stack auction platform for vintage and designer heels.

    Auctionary allows users to create an account, sign in, browse and search auction listings, list items for sale, place bids and ask questions about individual listings.

    I built a Vue frontend that communicates with a REST API developed using Node.js and Express. The backend uses an SQLite database to manage users, auction items, bids and questions. It also includes input validation, password hashing, session-based authentication and automated API testing.

    This project strengthened my understanding of how frontend, backend and database components work together within a complete application. It was originally completed as a university Full Stack Development assignment and received a mark of 80%. I later refreshed the visual design for my portfolio while retaining the assessed functionality.

    Technologies: Vue, JavaScript, Node.js, Express and SQLite.

  • Configurable Board Game Simulator

    Project type: Configurable Java board-game engine with a visual web interface.

    This project simulates a traditional race-style board game. Games can be configured with different board sizes, numbers of players and dice, end rules, collision rules and teleport rules.

    The original version was completed as a university programming assignment. After reviewing my tutor’s feedback, I returned to the project to correct problems in the game behaviour, demonstrate a wider range of rule configurations and improve the separation between the game logic and the application layer.

    I also added automated tests and moved the main game loop into the domain layer so that the core game can be reused independently of its output. I am currently developing a browser-based interface that will allow the different game configurations and results to be displayed visually.

    Technologies: Java, Spring Boot, Maven, JUnit, HTML, CSS and JavaScript.
